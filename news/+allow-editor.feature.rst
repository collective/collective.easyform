Allow Editors wherever Owners are allowed

Users with the Owner role can edit form fields, download saved data, and
perform other actions. Users with the Editor role should also be able to
perform these actions, as editing content is the purpose of this role.

Grant the Editor role the following permissions:

- collective.easyform: Add Content
- collective.easyform: Add Mailers
- collective.easyform: Add Data Savers
- collective.easyform: Edit Advanced Fields
- collective.easyform: Edit Mail Addresses
- collective.easyform: Download Saved Input
